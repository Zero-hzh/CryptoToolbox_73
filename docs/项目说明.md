# 项目说明

## 一、项目背景

密码学是信息安全的核心基础。对于计算机专业学生而言，仅靠理论学习难以真正理解凯撒密码、哈希、对称加密等算法的实际运作方式。本项目旨在通过一个直观的 Web 工具，让用户亲手体验加密与解密过程，加深对密码学原理的理解。

## 二、项目目标

1. 提供一个零门槛、零依赖的密码学演示工具
2. 覆盖古典密码（凯撒）、编码（Base64）、哈希（MD5/SHA）与对称加密（AES）四大类
3. 作为开源项目，实践 GitHub 协作流程（分支管理、Issue、Pull Request）

## 三、核心设计

### 1. 技术选型
- 纯静态页面，无需后端，降低部署成本
- 使用浏览器原生 Web Crypto API，保证加密安全性
- 响应式设计，适配桌面与移动端

### 2. 加密实现
- **凯撒密码**：字符位移，`(c + shift) % 26`
- **Base64**：使用 `TextEncoder` 正确处理 UTF-8，避免中文乱码
- **哈希**：调用 `crypto.subtle.digest`，输出十六进制摘要
- **AES**：AES-GCM 模式 + PBKDF2 口令派生，输出 `iv:密文` 格式
