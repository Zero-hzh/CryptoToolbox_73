# 使用手册

## 环境要求

- 任意现代浏览器（Chrome / Edge / Firefox / Safari）
- 无需安装任何依赖

## 启动方式

1. **直接打开**：双击 `index.html` 文件
2. **本地服务器**（推荐）：
   ```bash
   cd CryptoToolbox_73
   python -m http.server 8080
   ```
   浏览器访问 `http://localhost:8080`

> 提示：AES 功能依赖 Web Crypto API，需在 HTTPS 或 `localhost` 环境下使用。

## 功能操作指南

### 凯撒密码
- 位移量范围 1~25
- 示例：明文 `HELLO`，位移 3 → 密文 `KHOOR`

### Base64
- 支持中文，示例：`你好` → `5L2g5aW9`

### 消息摘要
- MD5：`hello` → `5d41402abc4b2a76b9719d911017c592`
- SHA-256：输出 64 位十六进制

### AES 加解密
1. 加密：输入明文 + 口令 → 得到 `iv:密文`
2. 解密：将 `iv:密文` 粘贴回输入框 + 相同口令 → 还原明文

## 常见问题

**Q：Base64 解码报错？**
A：请确认输入是合法的 Base64 字符串。

**Q：AES 解密失败？**
A：请确认口令正确，且密文格式为 `iv:密文`（冒号为英文半角）。
