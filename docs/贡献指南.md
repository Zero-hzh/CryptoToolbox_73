# 贡献指南

感谢你对 CryptoToolbox 的关注！欢迎通过以下方式参与贡献。

## 提交 Issue

当你发现 Bug 或有新功能建议时，请：
1. 先在 Issues 中搜索是否已存在类似问题
2. 提供清晰的问题描述、复现步骤、环境信息

## 提交 Pull Request

1. **Fork** 本仓库
2. 创建功能分支：
   ```bash
   git checkout -b feature/你的功能名
   ```
3. 提交代码（遵循规范）：
   ```bash
   git commit -m "feat: 添加新功能描述"
   ```
4. 推送分支并创建 Pull Request

## 代码规范

- 提交信息格式：`feat:` / `fix:` / `docs:` / `refactor:`
- JavaScript 使用 ES6 语法
- 保持代码风格一致（2 空格缩进）

## 行为准则

- 友善、尊重地交流
- 不提交包含恶意代码的改动
- 遵守 MIT 许可证
