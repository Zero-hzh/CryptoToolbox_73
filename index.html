CryptoToolbox 密码学工具箱

一个纯前端、零依赖的密码学学习与演示工具，支持凯撒密码、Base64 编解码、消息摘要（MD5/SHA）与 AES 对称加密。

纯前端 零依赖 MIT 许可证

凯撒密码 Caesar Cipher

将字母按固定位移量进行替换的经典古典密码，位移量（密钥）范围 1~25。

Base64 编解码

将二进制数据编码为可打印 ASCII 字符的编码方式，广泛用于数据传输。

消息摘要 MD5 / SHA

生成输入内容的哈希摘要，用于校验数据完整性。注意：MD5 已不再安全，仅用于教学演示。

AES 对称加密

基于 Web Crypto API 的 AES-GCM 加解密，密钥通过口令派生。
